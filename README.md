# Solitaire_Project

Solitaire Game for Console, Written in Python.

A playable **Klondike Solitaire** for the terminal, made as a university project (L3 MIAGE, Université Toulouse Capitole).

> The in-game interface is in French.

## Features

- 3 difficulty levels (draw 1 or 3 cards, hints on or off)
- Multi-card moves between columns
- Undo, prioritised hints, save/load to JSON

## Run

```bash
pip install colorama
python Solitaire_Project.py
```

Type `commandes` in the game to see all available commands.
